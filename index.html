What really happens

      
When you tap Check, one resized photo (no GPS data) goes from your phone to our small Render server, which sends it to Google's hosted Gemma model and returns the answer. Our server code does not save photos. Google's own API terms apply to what it receives. If you want zero upload, do not tap Check. Gemma is open-weight, so anyone can self-host it to avoid the cloud. Trail session data stays in this browser only.
